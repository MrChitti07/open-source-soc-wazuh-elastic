MSc project: Design and Empirical Evaluation of an Open-Source SIEM-Based SOC for SMEs using Wazuh and the Elastic Stack
This repository contains my MSc Advanced Computer Science project.

Project Title:
Design and Empirical Evaluation of an Open-Source SIEM-Based SOC for SMEs
Using Wazuh and the Elastic Stack

Author:
Ravichandrareddy Chitti

University:
University of Hertfordshire

This project demonstrates a functional open-source Security Operations Centre
(SOC) designed for Small and Medium-Sized Enterprises (SMEs).

The system uses:
- Wazuh
- Elastic Stack
- Sysmon
- File Integrity Monitoring
- MITRE ATT&CK framework

The artefact shows centralized security monitoring, alerting,
and dashboard-based analysis using open-source tools.
